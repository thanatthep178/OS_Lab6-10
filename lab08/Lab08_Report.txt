1.ทำไม SCAN เคลื่อนหัวอ่านน้อยกว่า FCFS?
ตอบ FCFS ให้บริการตามลำดับคำขอทำให้หัวอ่านเคลื่อนกลับไปกลับมา รวม 640 cylinders 
    ส่วน SCAN ให้บริการระหว่างเคลื่อนไปทางเดียวกันจนถึงขอบ 199 แล้วจึงย้อนกลับ จึงเคลื่อนรวม 331 cylinders ลดลง 48.28% สำหรับชุดข้อมูลนี้

2.I/O Bound หมายถึงอะไร?
ตอบ งานมีความเร็วจำกัดจากการรอรับ–ส่งข้อมูล มากกว่าความเร็วในการคำนวณ ระหว่างรอ I/O กระบวนการนั้นอาจหยุดรอ 
    ทำให้ CPU ว่างหากไม่มีงานอื่นพร้อมทำ แต่ถ้ามีงานอื่น ระบบปฏิบัติการสามารถให้ CPU ทำงานอื่นได้ จึงไม่ได้หมายความว่า CPU ทั้งเครื่องต้องว่างเสมอ

3.ทำไมไฟล์ภาพจำนวนมากทำให้ GPU รอข้อมูล?
ตอบ การเปิดไฟล์จำนวนมากเพิ่มภาระค้นหาข้อมูลไฟล์ ตรวจสิทธิ์ และเปิด–ปิดไฟล์ หากส่งข้อมูลเข้า GPU ไม่ทัน GPU จะต้องรอ การรวมข้อมูลเป็นไฟล์หรือชุดไฟล์ที่อ่านต่อเนื่องช่วยลดภาระนี้ 
    ผลทดลองพบว่าไฟล์เล็กใช้เวลา 0.030150 วินาที ส่วนไฟล์ใหญ่ใช้เวลา 0.000692 วินาที อย่างไรก็ตาม การทดลองนี้ไม่ได้ใช้ GPU จริง จึงไม่ได้วัดเวลาที่ GPU ว่างโดยตรง
