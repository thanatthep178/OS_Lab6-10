1.ทำไม LRU เกิด Page Fault น้อยกว่า FIFO
ตอบ เพราะ FIFO เอาหน้าที่เข้า RAM ก่อนออกก่อน ส่วน LRU เอาหน้าที่ไม่ได้ใช้นานที่สุดออก 
    ชุดข้อมูลนี้เรียกหน้าเดิมซ้ำ เช่น หน้า 2 จึงได้ประโยชน์จากการเก็บหน้าที่เพิ่งใช้งาน ทำให้ LRU เกิด Fault 7 ครั้ง เทียบกับ FIFO 9 ครั้ง

2.Thrashing คืออะไร และทำไมฝั่งอ่าน–เขียนไฟล์จึงใช้เวลามากกว่า
ตอบ Thrashing คือภาวะที่ระบบใช้เวลาสลับหน้าระหว่าง RAM กับอุปกรณ์เก็บข้อมูลมากจนทำงานจริงได้น้อยลง ในโค้ดนี้ฝั่ง File I/O ต้องเปิด อ่าน เขียน และปิดไฟล์ซ้ำจึงต้องทำงานเพิ่ม 
    โดยวัดได้ 1.4354 วินาที เทียบกับ RAM 0.4556 วินาที ทั้งนี้สคริปต์ไม่ได้ทำให้ RAM เต็มจริง และผลยังได้รับอิทธิพลจากแคชและการคำนวณที่ต่างกันของสองฝั่ง

3.ลด batch_size ช่วยอย่างไร
ตอบ ทำให้แต่ละรอบประมวลผลข้อมูลน้อยลง จึงลดหน่วยความจำที่ใช้เก็บข้อมูลและค่าระหว่างคำนวณ หากข้อมูลที่กำลังใช้งานพอดีกับ RAM ระบบก็ลดความจำเป็นในการสลับหน้าได้ 
    ส่วนกรณี GPU หน่วยความจำเต็ม การลด batch size ช่วยลดการใช้ VRAM แต่เป็นคนละกรณีกับ OS swapping ใน RAM
